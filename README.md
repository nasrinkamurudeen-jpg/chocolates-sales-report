# 🍫 Chocolate Sales Analysis using Power BI

## 🔍 Project Overview
This project focuses on analyzing chocolate sales data using Power BI to generate meaningful business insights through interactive dashboards.

## 📁 Dataset
The dataset includes:
- Product details
- Sales amount
- Category (Bars, Bites, Other)
- Team performance
- Region-wise sales
- Shipment status

## ⚙️ Tools Used
- Power BI
- Excel

## 📊 Dashboard Features

### 📌 Total Sales by Category
- Visualizes sales distribution across categories like Bars, Bites, and Other

### 📌 Total Sales by Team
- Shows contribution of different teams (Delish, Yummies, Jucies, Tempo)

### 📌 Total Sales by Product
- Displays top-performing chocolate products

### 📌 Sales by Person
- Individual performance of salespersons

### 📌 Shipment Status Analysis
- Delivered vs Shipped orders using tree map visualization

### 📌 Filters / Slicers
- Category filter
- Region filter (Americas, APAC, Europe)
- Team filter
- Product ID filter

## 📈 Key Insights
- Bars category generates the highest revenue
- Certain products dominate overall sales
- Majority of shipments are successfully delivered
- Team performance varies significantly across regions

## 🎯 Outcome
This dashboard helps in:
- Understanding product performance
- Tracking sales trends
- Improving decision-making for business growth
